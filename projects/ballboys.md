I attended a CIS4930 class at UNF where the final (group, but I completed it alone) project was "a simple 2D game with a goal and reward."
So I made a 3D multiplayer (up to 10 per game) platformer with procedurally generated maps... and a cosmetics system with RGB customization.
I did all of this within the 4-5 months of the class starting/ending... and I obtained approval for a Steam release. (first ever Steam application from me)
There will be a recorded UNF Computing Symposium presentation on the project mid-December.
